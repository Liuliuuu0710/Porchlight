# iPhone 13 mini / OPPO Find X8 适配

更新于 2026-10-14。适用范围：手机 HTML 交互原型。

## 屏幕基准

| 测试机 | 官方屏幕参数 | 页面布局基准 |
| --- | --- | --- |
| iPhone 13 mini | 5.4 英寸，1080 × 2340，476 ppi | 375 × 812 逻辑尺寸；物理像素不直接用作 CSS 宽度 |
| OPPO Find X8 | 6.59 英寸，1256 × 2760，460 PPI | 弹性视口；412 × 915 作为测试样例，另检查 360 / 393 / 430 宽度 |

官方来源：[Apple 技术规格](https://support.apple.com/zh-cn/111873)、[OPPO 技术规格](https://www.oppo.com/cn/smartphones/series-find-x/find-x8/specs/)。两份屏幕规格已读取核对。Android 的逻辑宽度随显示大小、浏览器和系统栏变化，不能由物理分辨率直接确定。

## 本次改动

- iOS 按钮至少 44 × 44 CSS px，Android 至少 48 × 48 CSS px；原生迁移分别对应 Apple HIG 的 pt 与 Material 的 dp 设计基准。
- 顶部品牌和原型标签分行，小屏不挤压；主画面按比例缩放，保持四个导航入口。
- 使用系统字体；输入框字号至少 16px，避免 iOS 默认聚焦放大，保留手动缩放能力。
- 页面与底栏读取上下左右 safe-area；日期表单改为单列，弹层独立滚动。
- 基于 visualViewport 调整输入时可用高度和弹层位置，检测到键盘时隐藏底栏。
- 访客通话按钮补足文字对比度；保留示例画面和未接入能力的提示。

原生设计参考：[Apple HIG Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)、[Material Accessibility](https://m3.material.io/foundations/accessible-design/accessibility-basics)。当前仍是 HTML 页面，不代表完成原生导航、系统返回或系统控件接入。

## 已验证与待验收

Chromium 模拟 375 × 812、412 × 915、360 × 800、393 × 873、430 × 932 和横屏 812 × 375：四页无横向溢出、可见按钮满足最小触控尺寸、弹层无横向溢出；计划新增保存/刷新读取、记忆新增、消息去向弹层通过，无页面脚本错误。截图见 validation 文件夹。这些是桌面浏览器验证，不等同于 Safari / ColorOS 真机验证。

请分别在 iPhone Safari 与 OPPO 常用浏览器检查：

1. 记录系统、浏览器版本和显示大小设置；顶部与底栏避开刘海/挖孔及手势区。
2. 打开日期表单与对话输入，呼出/收起键盘后仍能滚动到保存或发送；横竖屏切换后恢复正常。
3. 开启大字体或页面缩放，检查长计划和长记忆换行、按钮文字不截断。
4. 页面滚到底部，末条内容不被导航覆盖；Android 手势/三键导航均检查。
5. 刷新后确认计划和记忆仍在；语音和对讲仍只是原型演示。

若后续封装 WKWebView / Android WebView，需由原生容器正确提供系统栏与键盘 Insets，并重新进行真机验收。
