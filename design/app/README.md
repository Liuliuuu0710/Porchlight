# Porchlight 手机端交互原型

`index.html` 是基于 V1 与 V2 Web 交互合并制作的手机端页面：

- 此刻：首页视频示例、Homi 提示、短期计划和长期记忆入口
- 计划：新增、修改时间、结束与重新启用
- 记忆：修改习惯文字、图片位置关联、暂停与恢复
- 对话：文字输入、语音状态演示、消息去向选择
- 访客通话：保留会议中的视频拖动方向，明确当前 Web SDK 未接通双向对讲
- 使用 `localStorage` 保存本机示例数据，未连接设备、模型或 ASR

直接打开 `index.html` 即可查看，也可以用手机浏览器访问本机静态服务。页面适合继续迁移到 iOS / Android 原生工程，当前不是可安装的原生 App。

## 两台测试机适配

已按 iPhone 13 mini 和 OPPO Find X8 调整触控、安全区、小屏表单与弹层。打开 [双机预览](devices.html)，或查看 [设备适配说明及真机验收项](设备适配说明.md)。真实手机使用 index.html，不带 preview 参数。
