# 留灯简洁版 · 后端联调与开发执行工作文档

更新：2026-10-14。基准：恢复后的浅色淡紫手机原型，适配 iPhone 13 mini、OPPO Find X8。

> 本文为建议实施契约，接口尚未实现。当前状态依据 app/index.html、mobile.css、mobile.js 核对；旧 V1/V2 文档只作背景，不代表手机端具备相同能力。

## 1. 入口与范围

- [双机离线预览](留灯-简洁版恢复-双机离线预览.html)：评审使用。
- [前端源页面](index.html)：迁移与联调基准。
- [设备适配说明](设备适配说明.md)：真机检查依据。
- [历史 V2 交接](../开发交接说明-V2.md)。

两台手机共用一套 API、领域模型与业务规则，只在安全区、键盘、权限及 SDK 适配上区分。正式联调使用 HTTPS Web 应用或经过验证的原生容器；离线 HTML 不承担正式设备鉴权和服务端运行。

第一阶段：账号权限 → 设备状态/画面 → 计划/记忆持久化 → 文字草稿确认。第二阶段：语音、证据图分析与反馈。对讲以 SDK 真机验证通过为前置条件。

## 2. 当前实现与缺口

| 模块 | 当前状态 | 开发要求 |
| --- | --- | --- |
| 此刻 | 露台示例图、固定 Homi 文案 | 接真实取流、设备状态；首帧到达后才标记直播 |
| 计划 | 本地新增、改时间/内容、结束、重新启用 | 数据库持久化、版本、服务端时间状态；当前 enabled 只是开关 |
| 记忆 | 本地编辑、位置标签、暂停/恢复 | 来源、版本、真实图片/区域关联；region 文字不是视觉识别结果 |
| 对话 | 文字输入和去向弹层 | 当前 sendMessage 未把原话带入编辑表单；补传参、草稿、持久化 |
| 语音 | 延时填入固定句子 | 没有录音/ASR；实现按住、松开、取消及权限状态 |
| 访客对讲 | 按钮文案预览 | 不录音、不发送声音；必须独立验证 SDK 能力 |
| 存储 | index 使用 porchlight-mobile-v1 | 服务端作为正式数据源；双机离线包使用独立演示键，不直接导入正式账号 |
| AI 变化确认 | 恢复版中没有此卡片 | 需另做证据、分析和确认闭环，不复用霓虹版的模拟成功作为验收 |

先补前端：原话进入草稿；保存成功才关闭表单；失败保留输入；加载/无内容/失败分开；禁止重复提交。恢复示例数据仅用于演示环境。

## 3. 职责划分

| 角色 | 负责交付 |
| --- | --- |
| 前端 | 页面迁移、API client、草稿编辑、状态与错误提示、两机适配 |
| 后端 | 家庭权限、数据库、计划/记忆版本、草稿确认事务、AI/ASR 适配、审计 |
| 设备接入 | SDK 版本/型号/平台能力矩阵、真实首帧、断线恢复、对讲与控制验证 |
| 产品/验收 | 冻结字段语义、准备演示数据、人工判断 AI 输出、登记未完成项 |

建议 MVP 复用团队技术栈：业务服务＋关系数据库＋受限媒体存储，慢任务用持久任务表/队列处理。不要求先拆微服务。视频按官方 SDK 协议传输，不用普通 JSON API 搬运视频。

模型 Key、设备长期凭据保存在服务端；仅在 SDK 必需时下发短有效期、受限的客户端参数。设备能力未知时返回 unknown，不假装支持。

## 4. 数据模型（建议）

所有业务记录包含 id、householdId、createdAt、updatedAt、version。服务端生成 ID，校验资源家庭归属，不能信任客户端传来的 userId。

| 实体 | 字段 |
| --- | --- |
| Device | name、provider、model、connectionState、lastSeenAt、capabilities；摄像头与基站状态分开 |
| Plan | deviceId、text、startsAt、endsAt、timeZone、enabled、status |
| Memory | deviceId、text、enabled、imageId?、regionId?、source |
| Region | deviceId、imageId、label、geometry?；坐标若启用则归一化到 0–1，并绑定图片 |
| Evidence | deviceId、capturedAt、imageId、origin、expiresAt；真实帧与示例数据分开 |
| Draft | kind、originalText、proposedFields、targetId?、baseVersion?、status、expiresAt |
| Analysis | evidenceId、status、summary?、relatedPlanIds、relatedMemoryIds、modelVersion、error? |
| Feedback | analysisId、decision、correction?、confirmedBy；不代表自动训练模型 |

### 时间与生效语义

- API 使用带偏移的 ISO 8601 时间，数据库 UTC，保留 IANA timeZone，例如 Asia/Shanghai。
- datetime-local 无时区，前端转换后提交；结束时间必须晚于开始时间，前后端都校验。
- 服务端结合 enabled 和当前时间计算 scheduled / active / ended / expired。手动关闭为 ended；过去的启用计划为 expired。
- 重新启用过期计划必须先修改时间，不能继续显示正在生效。
- 第一阶段计划仅供观察/提醒上下文，不自动移动设备或开门。设备控制需要独立命令契约与用户授权。
- 暂停记忆后不参与新分析；已排队任务记录引用版本，结果可能过期时明确标注。

## 5. 建议 API

前缀 /api/v1。成功统一返回 data、requestId；列表 data 包含 items、nextCursor。以下路径为建议，不是现有后端能力。

| 方法 / 路径 | 用途 | 约束 |
| --- | --- | --- |
| GET /session | 用户、家庭、权限 | 复用团队鉴权方案 |
| GET /devices | 设备与能力列表 | 支持/不支持/未知分开 |
| GET /devices/{id}/status | 连接与最后在线时间 | 未知不等于离线 |
| POST /devices/{id}/live-sessions | 创建取流授权 | 返回会话 ID、协议、有效期、适配器参数 |
| DELETE /live-sessions/{id} | 回收会话 | 可重复调用，服务端超时兜底 |
| GET /plans?deviceId=... | 计划列表 | 分页、服务端计算状态 |
| POST /plans | 新增计划 | 幂等键、时间校验 |
| PATCH /plans/{id} | 编辑/结束/重新启用 | version 校验，返回完整新记录 |
| GET /memories?deviceId=... | 记忆列表 | 包含暂停记录 |
| POST /memories | 新增记忆 | 用户确认来源 |
| PATCH /memories/{id} | 编辑/暂停/恢复 | version 校验 |
| GET /devices/{id}/regions | 位置列表 | 返回关联图片及区域 |
| POST /drafts | 原话生成计划/记忆草稿 | 不写正式记录；歧义返回 needsClarification |
| POST /drafts/{id}/confirm | 核对后提交 | edits、baseVersion、幂等键；事务写入 |
| POST /drafts/{id}/cancel | 取消草稿 | 不影响原记录 |
| POST /transcriptions | 音频转写 | multipart 上传，限格式/大小/时长；返回 jobId |
| GET /jobs/{id} | 查询慢任务 | queued/running/succeeded/failed/cancelled |
| POST /jobs/{id}/cancel | 取消任务 | 终态不回退；迟到响应不可覆盖新输入 |
| POST /analyses | 证据图分析 | 只接受有权访问的 evidenceId，不接受任意远程 URL |
| GET /devices/{id}/analyses | 分析记录 | 含证据时间、上下文版本和失败原因 |
| POST /analyses/{id}/feedback | 确认/纠正 | 写长期记忆仍需单独确认 |

对讲接口待 SDK 验证后定义；后端接口本身不能补足缺失的设备音频能力。

### 请求示例

创建计划：deviceId=device_demo，text=园丁来照料植物，startsAt=2026-10-17T09:00:00+08:00，endsAt=2026-10-17T11:00:00+08:00，timeZone=Asia/Shanghai，enabled=true。

日期仅作协议示例，演示数据按实际测试日期生成。更新时额外携带 version；返回服务端新 version 和 status。

### 错误与一致性

错误返回 error.code、error.message、error.retryable、error.fieldErrors、requestId。

| 状态 | 处理 |
| --- | --- |
| 400/422 | 字段/时间不合法，原表单内定位错误 |
| 401/403 | 会话失效/无权限，不显示其他家庭资源 |
| 404 | 对象不存在，保留输入，重新选择目标 |
| 409 VERSION_CONFLICT | 返回最新记录供比较，不静默覆盖 |
| 429/503 | 按 Retry-After 有限退避，提供手动重试 |

- 创建和确认带 Idempotency-Key：同键同内容返回同一结果，同键不同内容拒绝。
- 草稿 pending → confirmed 与业务写入在同一数据库事务内；已确认草稿重试返回原结果。
- GET 可有限重试；修改请求仅在幂等契约成立时重试。超时不等于未写入。
- 客户端保存中禁重复提交；网络失败保留内容。服务端仍要做并发控制。

## 6. 联调流程

### A. 此刻 / 真实画面

1. 拉取家庭设备与能力，申请直播会话。
2. 前端 SDK 收到第一帧后才显示直播，拿到授权不算成功。
3. 显示设备状态、画面时间，AI 状态单独显示。
4. 断线后标记最后画面为历史，给重试/排查入口；离开页释放资源。

### B. 计划 / 记忆

1. 读取列表，分开加载、空列表、失败。
2. 编辑携带版本，保存成功后以服务端结果替换卡片并关闭弹层。
3. 失败保留输入；刷新、跨手机仍读取同一服务端数据。
4. 两机并发修改必须出现冲突提示；暂停记忆与结束计划更新页面计数及分析上下文。

### C. 文字 / 语音到草稿

1. 原话保留为 originalText。ASR 最终结果进入可编辑输入，不自动提交。
2. 用户选择计划/记忆，再生成草稿；编辑表单必须带入原话。
3. “明天下午”无明确时间需补问；“把它改掉”匹配多条对象需选择目标。
4. 确认提交、取消无副作用；识别失败回退文字输入。
5. 对讲单独启动，助手录音不自动传给访客。

### D. 图像分析（第二阶段）

1. 由许可的 SDK 帧建立证据记录，标注来源和采集时间。
2. 按设备节流/去重/限制并发，采样与费用上限配置化，不逐帧请求模型。
3. 分析记录当时有效计划和记忆版本，返回证据与建议。
4. 用户确认或纠正，新增记忆仍需明确核对。
5. 超时/模型失败显示失败，不伪装成“没有变化”。

## 7. 开发执行顺序

| 顺序 | 工作 | 完成标准 |
| --- | --- | --- |
| P0-1 | 核实 SDK 平台/型号/版本 | 能力矩阵、首帧真机记录，确定 Web 或原生载体 |
| P0-2 | 冻结数据契约 | OpenAPI、错误码表、无密钥请求响应示例 |
| P0-3 | 鉴权与计划/记忆存储 | 数据库迁移、API 测试、跨设备读取通过 |
| P0-4 | 前端替换本地数据源 | 加载/错误/冲突提示，保存失败不丢输入 |
| P0-5 | 取流与状态 | 首帧、断连、重试、退出回收均可验收 |
| P0-6 | 文字草稿确认 | 原文传递、歧义补问、取消、幂等确认通过 |
| P1-1 | ASR | 两机权限/取消/超时/纠错通过，文字仍可用 |
| P1-2 | 分析与反馈 | 真实证据到人工确认闭环，失败也可展示 |
| 条件项 | 对讲/设备控制 | SDK 真机通过后实现；不支持时明确禁用 |

由团队为每项指定负责人和日期；本文不假定人员已承诺或赛事规则已确认。前端可先基于 mock 开发，但 mock 不能作为真实链路完成证据。

## 8. 验收清单（待执行）

- [ ] 同账号两台设备读取一致；越权访问其他家庭被拒绝。
- [ ] 新增、修改、结束/启用、暂停/恢复后刷新仍一致。
- [ ] 时间非法被前后端拦截；过期计划不显示生效中。
- [ ] 连点和超时重试只生成一条记录。
- [ ] 并发编辑触发版本冲突，不覆盖新内容。
- [ ] 草稿取消无副作用；确认可追溯原话、目标和版本。
- [ ] 未接入、离线、无内容、读取失败、分析失败文案分开。
- [ ] 首帧后才显示直播，历史画面有时间。
- [ ] 录音权限拒绝/取消/切后台正确收尾，无麦克风残留。
- [ ] 不支持对讲时不显示连接成功；通话结束释放资源。
- [ ] 两机键盘不遮保存、底栏不挡内容、长文本无横向溢出。
- [ ] iPhone 检查 375×812；OPPO 按实际浏览器视口并覆盖 412×915 样例。
- [ ] 前端包、离线 HTML、仓库、日志无长期凭据或模型 Key。

历史模拟检查不能替代新后端联调和真机验收。两机分别记录系统版本、浏览器版本、显示缩放、验收人、结果和失败截图。

## 9. 环境与发布交接

- 交付 .env.example，只列变量名：DATABASE_URL、MODEL_API_BASE、MODEL_API_KEY、MODEL_NAME、DEVICE_PROVIDER、ASR_PROVIDER、MEDIA_RETENTION_DAYS 等；真实值走团队密钥渠道。
- 补数据库迁移、启动、健康检查、回滚、任务重试、测试账号和样例数据说明。
- 正式页面 HTTPS；限制 CORS 来源。Cookie 会话配置 Secure/HttpOnly/SameSite，按部署方式落实 CSRF 防护。
- 媒体需授权访问、短效链接；设置保留期和删除机制，上传家庭画面给模型需用户授权。
- 日志仅记录必要 requestId、耗时、状态及供应商错误码，不记录令牌或未脱敏原始媒体。
- 演示/真实环境分开，不能在生产调用“恢复示例数据”。
- 前端修改后重新生成离线双机 HTML，避免内嵌版本与源页面不一致。

## 10. 开工前冻结的决策

1. Web/iOS/Android 哪个载体先接设备？具体 SDK 版本、支持矩阵是什么？
2. 登录方式、家庭/设备绑定规则、测试域名由谁提供？
3. 模型/ASR 接口、格式、额度、数据处理条件是什么？
4. 帧采样频率、超时、录音长度、媒体保留期采用什么上限？
5. 计划是否仅作观察上下文？硬件动作另行定义，不隐式执行。

以上不阻塞计划/记忆数据库、接口 mock 和表单异常状态的先行开发。
